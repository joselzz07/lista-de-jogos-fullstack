# Lista de Jogos - API Backend

Backend em Node.js com PostgreSQL e JWT para gerenciamento da Lista de Jogos.

## 🚀 Como Executar Localmente
1. Instale as dependências: `npm install`
2. Configure o arquivo `.env` com sua string do PostgreSQL.
3. Inicie o servidor: `npm run dev`
